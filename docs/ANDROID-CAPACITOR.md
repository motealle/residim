# اپ اندروید با Capacitor — ایده‌ها

همین PWA در یک پوسته‌ی Capacitor بسته می‌شود؛ کد وب مشترک می‌ماند و فقط جاهایی که توانایی بومی ارزش می‌سازد افزونه می‌گیرند.

| توانایی بومی | افزونه | ارزش برای رسیدیم |
|---|---|---|
| موقعیت پس‌زمینه با geofence | `@capacitor-community/background-geolocation` | ثبت خودکار «رسیدیم» وقتی ماشین به مدرسه یا خانه می‌رسد، حتی با صفحه‌ی خاموش (ویژگی اشتراک) |
| اعلان واقعی (FCM) | `@capacitor/push-notifications` | دعوت، جایگزین امروز، «فرزندتان رسید» بدون هزینه‌ی پیامک |
| خواندن خودکار کد پیامک | SMS User Consent / Retriever | ورود بدون تایپ کد |
| مخاطبان | `@capacitor-community/contacts` | دعوت از والدین هم‌کلاسی با یک تپ (با اجازه‌ی کاربر) |
| اشتراک‌گذاری بومی | `@capacitor/share` | فرستادن لینک و پوستر به ایتا، بله، واتس‌اپ |
| تقویم | `@capacitor-community/calendar` | نوبت رانندگی هفته در تقویم گوشی |
| بیومتریک | `@capacitor-community/biometric-auth` | قفل بخش حساب و تسویه |
| ویجت صفحه‌ی اصلی | پلاگین سفارشی | «امروز نوبت کیست؟» بدون باز کردن اپ |
| Android Auto | پلاگین سفارشی | فهرست سوار شدن‌ها روی صفحه‌ی ماشین |
| پرداخت درون‌برنامه | Bazaar / Myket IAB | اشتراک «همراه» از کافه‌بازار و مایکت |

ترتیب پیشنهادی: ۱) پوسته + اعلان + اشتراک‌گذاری؛ ۲) رسیدن خودکار با geofence؛ ۳) پرداخت بازار؛ ۴) ویجت.
انتشار در کافه‌بازار و مایکت؛ نسخه‌ی وب همیشه باقی می‌ماند.

## ساخت و انتشار (از نسخه‌ی ۱۵)
- کد پوسته در `android-app/`: `capacitor.config.json` (شناسه‌ی `ir.residim.app`، نام «رسیدیم»، `server.url = https://residim.ir/`، UA با `ResidimApp/<نسخه>`)، `setup.sh` (مجوزها، آیکون از `landing/assets/icon-512.png`، اسپلش سبز، نسخه)، `www/index.html` (صفحه‌ی بی‌اینترنت).
- افزونه‌ها: `@capacitor/local-notifications` (یادآوری ۲۰:۳۰ شب قبل، کانال‌های «رسیدیم» و «نوبت فردا»)، `@capacitor/haptics`، `@capacitor/app` (دکمه‌ی بازگشت)، `@capacitor-community/background-geolocation` (سرویس پیش‌زمینه در سفر).
- چون اپ همان سایت را باز می‌کند، هر انتشار وب فوراً به اپ هم می‌رسد؛ APK فقط وقتی دوباره ساخته می‌شود که `android-app/` عوض شود (یا دستی: Actions ← Android app ← Run workflow).
- نسخه: `android-app/version.txt`؛ versionCode = ۱۰۰ + شماره‌ی اجرای CI.
- امضا: بار اول CI کلید RSA می‌سازد و فقط روی هاست در `app/storage/android/` (پوشه‌ی بسته) نگه می‌دارد؛ هرگز در گیت (مخزن عمومی است) یا لاگ نیست. **از این دو فایل پشتیبان بگیرید**؛ بدون همان کلید، نسخه‌ی بعدی روی نسخه‌ی نصب‌شده به‌روز نمی‌شود.
- خروجی: `residim.ir/app/residim.apk`، `residim-<نسخه>.apk` و `android.json` (نسخه، حجم، sha256) که منوی سایت از آن لینک و نسخه را نشان می‌دهد. نسخه‌ی APK در خود Actions هم به‌صورت artifact می‌ماند.
- FTPS در این Workflow با تأیید گواهی است. اگر گواهی FTP هاست معتبر نباشد، مرحله‌ی «Find the web root» می‌ایستد؛ در آن صورت گواهی معتبر روی FTP هاست لازم است.
- محدودیت فعلی: وقتی اپ کاملاً بسته است، پیام‌های تیم و «سوار شد» برای والدِ غیرراننده اعلان نمی‌شود (نیاز به FCM/Pushe)؛ یادآوری نوبت و ثبت خودکار راننده کار می‌کنند.
