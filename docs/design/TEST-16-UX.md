# تست ۱۶ — صحنه‌ی زنده‌ی سفر، تایپ پایدار، منوی مرتب

نشانی: `residim.ir` و `residim.ir/t/16/`

| بازخورد | علت / تغییر |
|---|---|
| کیبرد می‌پرید و متن جستجوی مدرسه خراب تایپ می‌شد | علت: هر ۴۰۰ میلی‌ثانیه بعد از تایپ، نتیجه‌ی جستجو کل ویزارد را دوباره می‌ساخت و فیلد عوض می‌شد. حالا فقط فهرست نتیجه‌ها تازه می‌شود. فوکوس خودکار روی گوشی و تبلت حذف شد (کیبرد خودش باز نمی‌شود)؛ فقط روی دستگاه با ماوس و کیبرد واقعی، فوکوس فوری. آزمون: تایپ نویسه‌به‌نویسه با مکث‌های متغیر، متن و فوکوس سالم. |
| ساعت شروع و پایان مبهم | «زنگ ورود (باید آنجا باشند)» و «زنگ تعطیلی (دنبال‌شان می‌رویم)» + یک خط توضیح |
| اسنپ درست باز نمی‌شد | پنجره‌ی اسنپ حالا در همان لمس باز می‌شود (قبلاً با تأخیر و توسط مرورگر گوشی مسدود می‌شد) و مقصد کپی می‌شود؛ راهنمای سه‌مرحله‌ای. اسنپ لینک عمومی برای پرکردن خودکار مقصد ندارد. |
| کاربر نفهمید باید پایین برود | دکمه‌ی شناور با دست اشاره به پایین: «N پیشنهاد هم‌مسیر پایین‌تر است»؛ با زدن یا رسیدن به فهرست محو می‌شود |
| اسلایدها طولانی | سه اسلاید کوتاه؛ اسلاید «زحمت» متحرک: دو نفر ½ ← سه نفر ⅓ ← چهار نفر ¼ با زوم‌اوت؛ «ما راننده نداریم 🙂»؛ پویش پوستر |
| تیم‌های بزرگ‌تر از یک خودرو | سرور: حداکثر ۴ مسافر، ۵ فقط اگر همه زیر ۹ سال؛ مسیرک‌های بزرگسال ۵ عضو. دعوت و پذیرش بیش از ظرفیت رد می‌شود. |
| آواتار هندسی | سایه‌ی سر و شانه در قاب دایره‌ای رنگی |
| «سوار شد» برنمی‌گشت | پیام با دکمه‌ی «برگرداندن» (برای ثبت خودکار هم) + لمس اسمِ سوارشده ← تأیید برگرداندن (عمل `unboard` در سرور) |
| پیش‌هشدار | «نفر بعدی شمایید» برای خانواده‌ی بعدی، «ماشین نزدیک است» (۱۰۰۰ متر، از قبل) و «نزدیک مدرسه‌اند» (۸۰۰ متر) |
| صفحه‌ی سفر شلوغ | **صحنه‌ی کارتونی** (کلید `trip_scene`، پیش‌فرض روشن): خانه‌ها پشت سر، مدرسه جلو (چپ)، ماشین با فنر، چرخ، خطوط سرعت، چراغ راهنمایی، ابرهای پیام («سارا منتظر باش؛ داریم می‌رسیم!»، «پریا سوار شد ✓»)، ساعت سوار شدن روی هر خانه، زنگ مدرسه، سرهای بچه‌ها در ماشین، زمان تقریبی رسیدن با موقعیت زنده یا زمان یادگرفته. ترتیب ایستگاه‌ها: نزدیک‌ترین بعدی از خانه‌ی راننده. |
| منو شلوغ | مسیرک‌ها اول با کارت روشن (رنگ نوع، مکان، وضعیت: تیم / دنبال هم‌مسیر / نیمه‌کاره) و چهار میانبر؛ دکمه‌ی اپ؛ دو کشوی «راهنما و ارتباط» و «تنظیمات»؛ ورود/خروج داخل تنظیمات |
