# تست ۲۷ — رسیدیم برای مدارس

| درخواست | تغییر |
|---|---|
| متن بسم‌الله بالاتر داخل ابر و ظاهر شدن از راست‌تر | متن ۸ واحد بالاتر رفت. حرکت ابر از ۴۶px سمت راست شروع می‌شود (قبلاً ۱۴px). |
| صفحه‌ی مخصوص مدارس در `/schools` | صفحه‌ی اقناعی ماژولار شامل این بخش‌ها: <br>• قهرمان متحرک (مدرسه، بچه‌ها، خودروهای تیمی، پیام «رسید») <br>• برآورد زنده برای مدرسه <br>• ۴ قدم <br>• ۶ ارزش <br>• بخش ویژه‌ی «دانش‌آموزان از همه‌ی شهر» <br>• پیش‌نمایش پنل <br>• لیگ و رادیوی «راه مدرسه» <br>• بیمه (به‌زودی) <br>• تعرفه بر پایه‌ی دانش‌آموز (ماهانه، ترمی، سالانه) با «ارزش برای خانواده‌ها» <br>• اعتماد و پرسش‌ها <br>• فرم «از طرف مدرسه» و «والد هستم؛ معرفی می‌کنم» با فرستادن برای مدیر |
| پنل مدرسه | `#panel/TOKEN`: <br>• شاخص‌ها، سفرهای هفتگی، قطب‌نمای «از کجای شهر می‌آیند»، محله‌ها <br>• پیام به خانواده‌ها <br>• لیگ و رادیو <br>• QR و لینک مدرسه <br>• چاپ گزارش |
| لینک در منو | «رسیدیم برای مدارس» در منوی کناری و کشو. |

QA: صفحه و پنل در ۳۹۰ و ۱۴۴۰، API (درخواست، فعال‌سازی، پنل)، پیشخوان ← مدارس، smoke کامل؛ بدون خطا.
