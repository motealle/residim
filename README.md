# رسیدیم (Residim)

یک SaaS سبک برای «هم‌سرویس»‌های خانوادگی: برنامه رفت‌وبرگشت، جایگزینی نوبت، ثبت انجام و تسویه مشارکت.

## وضعیت فعلی

- مخزن در 2026-10-04 با یک لندینگ دود (smoke landing) راه‌اندازی شد.
- فایل لندینگ: `smoke/index.html`
- استقرار دود: `.github/workflows/ftp-smoke.yml`
- مقصد FTP ایزوله: `/residim-smoke/`
- هیچ مقدار Secret داخل مخزن ذخیره نشده است.
- اجرای اول FTPS به‌دلیل گواهی self-signed میزبان با خطای curl 60 متوقف شد.
- برای **تست دود فقط** اتصال همچنان رمزگذاری‌شده با FTPS است اما اعتبارسنجی گواهی با `--insecure` نادیده گرفته می‌شود.
- قبل از هر استقرار production باید گواهی معتبر میزبان نصب/استفاده شود (یا SFTP امن در صورت پشتیبانی).

## اصل محصول

**رسیدیم** برند محصول است و **هم‌سرویس** نام یک گروه رفت‌وآمد مشارکتی.

هسته MVP:
1. جدول هفتگی رفت/برگشت
2. تأیید آمادگی و درخواست جایگزین
3. ثبت انجام واقعی سفر
4. دفترکل مشارکت و تسویه شفاف
5. اعلان‌های مهم و دسترسی خانواده‌ای

## سیاست داده مکانی

نسخه اولیه فقط موقعیت رویدادمحور را با رضایت کاربر ثبت می‌کند (مثل «شروع سفر» یا «رسیدم»)، نه ردیابی دائمی کودک. آدرس دقیق و موقعیت زنده فقط باید برای اعضای مجاز همان گروه/سفر قابل دسترس باشد.

## مسیر فنی پیشنهادی

Laravel + MySQL/MariaDB + Blade/Alpine + PWA، روی هاست PHP دارای HTTPS و Cron. در MVP به‌جای WebSocket از polling کنترل‌شده استفاده شود؛ قابلیت‌های پرتکرار GPS/مسیریابی سنگین بعداً به زیرساخت مناسب‌تر منتقل شوند.
